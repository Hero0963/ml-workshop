# NOTICE — third-party material and attribution

Checked on 2026-09-25. This file lists everything in this project that comes from someone else,
under which terms, and how it is used.

## What is original

All code in `src/`, `scripts/`, `tests/` and `notebooks/`, all lesson text in `lessons/`, and all
figures in the executed notebooks were written or generated for this course.

- Algorithms are implemented from the equations and descriptions in the published papers and
  public course pages cited in each lesson and in `references.md`. **No code was copied** from
  any of the projects below; where a design is adopted, it is named in the lesson and here.
- No figures, slides or text passages from papers, courses or blog posts are reproduced.
  External material is only linked.
- The word2vec "toy world" corpus (`data.toy_world_corpus`), the web-like corpus of lab 10
  (`data_pipeline.make_web_corpus`, apart from the TinyStories stories it mixes in) and the
  addition task (`chat.AdditionProblem`) are generated by this project's code.

## Model weights (downloaded at run time, not redistributed)

### GPT-2 124M

- Files: `model.safetensors`, `vocab.json`, `merges.txt` from the Hugging Face mirror of the
  original release, <https://huggingface.co/openai-community/gpt2> (model card: MIT).
- Licence: OpenAI's Modified MIT License (<https://github.com/openai/gpt-2/blob/master/LICENSE>).
  It asks users to "use GPT-2 responsibly and clearly indicate your content was created using
  GPT-2".
- Use here: loaded into this project's `GPT` class in lab 05 and the network tests. The
  executed `notebooks/05_gpt2.ipynb` shows text generated by GPT-2; it is labelled as such in
  the notebook. The reference numbers in `tests/test_model.py` and `tests/test_tokenizer.py`
  (token ids, top-5 next tokens, maximum logits) were computed with Hugging Face
  `transformers` and OpenAI's `tiktoken` on 2026-09-25; neither package is a dependency of this
  project.

## Datasets (downloaded at run time, not redistributed)

### TinyStories

- Eldan, R. and Li, Y. (2023). "TinyStories: How Small Can Language Models Be and Still Speak
  Coherent English?" <https://arxiv.org/abs/2305.07759>. Data: <https://huggingface.co/datasets/roneneldan/TinyStories>.
- Licence: **Community Data License Agreement – Sharing, Version 1.0** (CDLA-Sharing-1.0),
  <https://cdla.dev/sharing-1-0/>.
- File used: `TinyStoriesV2-GPT4-valid.txt` (22.5 MB), stored in `data/`, which is ignored by
  git. It is split 90/10 into training and validation stories by `artifacts.course_stories`.
- Use here: training and evaluation data for every lab. Models trained on it and the text they
  generate are "Results" of Computational Use in the sense of the CDLA (section 1.11).
- **Excerpts shown in notebook outputs.** Some executed notebooks print short excerpts of
  TinyStories stories (lab 01 §1, lab 03 §1, lab 06 §1, lab 10 §0 and §5, lab 13). These excerpts
  are Data from TinyStories, published here unmodified under CDLA-Sharing-1.0, with credit to
  the Data Providers above. The rest of this project is not Data and is not covered by the CDLA.
