# notes/ — 做中學筆記（討論與決策的沉澱處）

> 本專案的定位是**做中學**：產出是理解，不是指標。
> 討論過程、決策取捨、被否決的選項如果只留在對話裡，下一個 session（或三個月後的自己）就要重問一次。
> 這裡是它們的落腳處。

## 和其他文件的分界

| 想寫的東西 | 該去哪 |
|---|---|
| **演算法原理的完整教材**：白話版＋專業版＋圖解＋數值推演（格式見 [`../rules.md`](../rules.md)「教材輸出格式」）| [`../../docs/`](../../docs/) |
| **討論與決策**：當時在想什麼、為什麼選 A 不選 B、被否決的選項與理由、還沒解決的疑問 | **本資料夾** |
| 某個實驗的方法、數字與結論 | [`../reports/`](../reports/) |
| 某天做了什麼（逆時序流水帳）| [`../dev_log.md`](../dev_log.md) |
| 現況與下一步、已定案決策的索引 | [`../roadmap.md`](../roadmap.md) |
| 某個里程碑的計畫、done 條件與檢查點 | [`../plans/`](../plans/) |

**判準**：價值在於「**下一個人不必再問一次為什麼**」→ 本資料夾；
價值在於「**把原理從頭教會一個人**」→ `docs/`；價值在於「**證明某件事在某天成立**」→ `reports/`。

## 寫作約定

- **繁體中文**；相對日期一律換絕對日期（`YYYY-MM-DD`，Asia/Taipei）。
- 一次討論一份，檔名 `YYYY-MM-DD-<主題>.md`；同一天的後續補充寫回同一份。
- **雙層講解**：先白話建立直觀，再補術語與正式定義。
- **數字要標出處**：本機給路徑（可加 `檔案:行號`），外部給真實連結。
- **標示信心**：實測、推論、還是猜測，要分得出來。沒量過的就寫「沒量過」。
