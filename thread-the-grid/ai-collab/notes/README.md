# notes/ — 做中學筆記（討論的沉澱處）

> **這個資料夾放「懂了什麼」，不是「做了什麼」。**
> 本專案的定位是**做中學**：產出是理解，不是指標。實驗數字會過期，對機制的理解不會——
> 但理解如果只留在對話裡，下一個 session（或三個月後的自己）就要重問一次同樣的問題。
> 這裡是它們的落腳處。

## 和其他文件的分界

| 想寫的東西 | 該去哪 |
|---|---|
| **這是什麼、為什麼這樣、怎麼判讀** — 概念、名詞、判準、心智模型 | **本資料夾** |
| 某天做了什麼、量到什麼（逆時序流水帳）| [`../dev_log.md`](../dev_log.md) |
| 某個實驗的完整方法與結論 | [`../reports/`](../reports/) |
| 量過的數字、踩過的坑、已定案的設計決策 | [`../rl-traps-and-facts.md`](../rl-traps-and-facts.md) |
| 現況與下一步 | [`../roadmap.md`](../roadmap.md) |
| 接手一條 track 要先知道的 | [`../handover-rl-solver.md`](../handover-rl-solver.md) |
| 某次任務的計畫與檢查點 | [`../plans/`](../plans/) |

**判準**：如果一段內容的價值在於「**下一個人不必再問一次**」，它屬於這裡；
如果價值在於「**證明某件事在某天成立**」，它屬於 `reports/` 或 `dev_log.md`。

## 寫作約定

- **繁體中文**；相對日期一律換絕對日期（`YYYY-MM-DD`，Asia/Taipei）。
- **雙層講解**：先白話建立直觀，再補術語與正式定義。
- **數字要標出處**：本機給路徑（可加 `檔案:行號`），外部給真實連結。
- **標示信心**：實測、推論、還是猜測，要分得出來。沒量過的就寫「沒量過」。
