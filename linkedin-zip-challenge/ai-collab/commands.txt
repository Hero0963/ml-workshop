[7] 常用指令
=====================================================================

cd linkedin-zip-challenge

uv sync                              # 建立/同步環境（Python 3.11）
uv run pytest                        # 全部測試
uv run pytest src/core/tests -v      # 只跑核心演算法
uv run ruff check .                  # lint
uv run python -m src.app.main        # 起服務 → http://localhost:7440/ui
python run_docker_dev.py             # Docker 開發環境（hot-reload → localhost:5173）
docker compose -f docker-compose.yml up --build -d   # 生產模擬
.\run_tests.bat                      # 跑測試並輸出報告到 src/core/tests/reports/

# Svelte 前端
cd src/custom_components/puzzle_editor/frontend
npm install && npm run build
